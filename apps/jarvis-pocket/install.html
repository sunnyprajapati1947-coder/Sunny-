Setup — 2 minute

  1. Download the APK

    Tap the button. Chrome will ask "allow the file download?" — allow it.

  2. Install it

    When the download finishes, tap it → allow Chrome/Files under "Install unknown apps".

  3. Open the app

    The Setup wizard opens on first launch: notifications, updates, AI brain — 3 taps.

  4. Add an AI key

    Free Gemini key: aistudio.google.com/apikey → paste → Save & test. The library works even without a key.

Straight talk

No analytics, no hidden uploads. API keys stay on the phone and requests go straight to the provider. Video is currently an AI script plus animated scenes rendered to WebM (real AI footage needs a paid API). Nothing is auto-posted without a tap — content is saved to the gallery and posted through the share sheet.

If the APK will not install, the browser version is here: jarvis-pocket-red.vercel.app (PWA — offline library, same UI).
