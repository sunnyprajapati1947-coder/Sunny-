HOW IT WAS MADE (no GPU, no cloud, no stock footage)
=========================================================
Every frame is generated by code in this repo (movie/):
  * 3D primitives (shaded spheres, capsules, extruded polygons) with Lambert +
    Blinn specular + rim light + contact shadows  -> 4 depth layers per shot
  * parallax camera (zoom / pan / drift) over those layers, LUT colour grade,
    vignette, film grain, 1920x1080 @ 24 fps -> x264
  * Devanagari subtitles shaped with HarfBuzz + FreeType (Pillow here has no
    Raqm, so shaping is done by hand)
  * Hindi narration: local eSpeak-NG (hi+m3) + EQ / double-tracking /
    compression / room reverb
  * score: procedural pads, bass, flute and bells with act-aware chord
    progressions; ambience (wind, birds, crickets) and SFX; voice-ducked mix

Rebuild:
  python3 movie/audio.py            # narration + soundtrack + timing
  python3 movie/make_film.py        # render 36 shots, concat, mux

Honest note on the 24 AI-video repos you sent: this machine has 2 CPU cores,
3 GB RAM and no GPU, while a single CogVideo/LTX/Hunyuan clip needs 8-40 GB
VRAM. They are catalogued with their VRAM needs in docs/REPOS.md, together with
the recipe to run them on a rented GPU and swap real AI keyframes into this
exact pipeline (movie/scenes.json already holds a text prompt per shot).
