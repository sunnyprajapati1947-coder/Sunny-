# The film pipeline — `movie/`

A self-contained **procedural CGI animation studio** for Hindi cartoon story
films. No GPU, no model weights, no stock footage, no paid APIs: every frame is
built from 3D primitives and shaded with numpy, every word of Hindi is shaped
with HarfBuzz, and the voice is synthesised locally with eSpeak-NG.

Output of the last run:

```
output/Neelu_aur_Gyaan_ka_Chashma_1080p.mp4   10:00, 1920x1080, 24 fps, Hindi voice + subtitles
output/Neelu_aur_Gyaan_ka_Chashma_thumbnail.jpg
```

## Why not the AI video repos?

See [`../docs/REPOS.md`](../docs/REPOS.md). Short version: this machine has
2 CPU cores, 3 GB RAM and **no GPU**; a single CogVideo/LTX/Hunyuan clip needs
8–40 GB of VRAM. So the 24 links you sent are catalogued, verified and documented
— and the film is generated by code that *can* run here. The pipeline is built so
that swapping in real diffusion keyframes later is a drop-in change
(`movie/scenes.json` already holds a text prompt per shot).

## How a single frame is made

```
scenes.json ──► lib/film.py        36 shot builders (staging, poses, palettes)
                  │
                  ├─ lib/scenes.py  environments + characters, all from
                  │                 shaded spheres/capsules/polygons
                  │                 (Lambert + Blinn spec + rim light + shadow)
                  └─ lib/cgilib.py  the renderer: masks, soft blobs, HarfBuzz text
                        │
                        ▼
              4 depth layers per shot (sky / ground / subject / foreground)
                        │
   render.py  ──►  parallax camera (zoom, pan, drift)  ─► LUT grade ─► vignette
                        │                                  ─► subtitles ─► x264
                        ▼
              build/seg/seg_XX.mp4
                        │
   make_film.py ──►  concat  ─►  mux with build/soundtrack.wav  ─►  output/
```

## The soundtrack

`movie/audio.py` builds all 10 minutes at once so music and narration share
absolute time:

| stem | technique |
|------|-----------|
| narration | eSpeak-NG `hi+m3`, then EQ (chest boost, 3 kHz notch), double-tracking, compression, small room reverb |
| music | procedural pads + bass + flute + bells, act-aware progressions (Dm–Bb–F–C / Bb–F–Gm–A / D–A–Bm–G) |
| ambience | filtered noise wind, birds by day, crickets at night |
| sfx | transition whooshes, magic bells on gadget shots, water burst in shot 30 |
| mix | narration RMS-normalised, music sidechain-ducked under the voice, tanh soft clip |

`audio.py` also *measures* the narration and stretches the film to exactly
`FILM_SECONDS` (default 600 s) by nudging the TTS rate — so the running time is a
constant, not a hope.

## Commands

```bash
# 1. re-record narration + score (≈2 min on 2 cores)  -> build/soundtrack.wav, build/timing.json
python3 movie/audio.py

# 2. render every shot (≈40 min on 2 cores; 2 parallel workers shown)
python3 -u movie/make_film.py --from 1  --to 19 &
python3 -u movie/make_film.py --from 20 --to 36 &
wait
python3 movie/make_film.py --assemble-only        # concat + mux -> output/

# QA tools
python3 movie/contact_sheet.py --out sheet.jpg --only 1,7,30   # grid of mid-frames
python3 movie/render.py --scene 7 --dur 14 --out /tmp/s07.mp4  # one shot
python3 movie/drive_upload.py --help-page                      # Drive options
```

## Staging contract (important when editing shots)

* `h` passed to `boy()` / `neelu()` / `adult()` is the **drawn height in canvas
  pixels** (canvas is 2304×1296; `H = 1296`).
* Standing heroes `0.42*H`, two-shots `0.34*H`, crowd `0.38*H`, wide `0.16*H`.
* Ground baseline `0.93*H`, rooftop `0.88*H`, indoors `0.86–0.90*H`.
* The foreground layer may only bite ~12 % into the frame from the edges,
  otherwise it hides the subject.
* `camera z` is clamped to 1.0–1.185 so no layer is ever *upscaled* — that is what
  keeps the plates sharp.

## Adding a shot

1. Add an entry to `movie/scenes.json` (`id`, `motion`, `narration`, `image`).
2. Add its palette in `movie/shots.json` (`{"12": {"pal": "day"}}`).
3. Write `def sNN(pal)` in `movie/lib/film.py`, return `_box([bg, mid, subj, fg], ...)`.
4. Re-run `movie/audio.py` (timing changes) then render that shot only.
